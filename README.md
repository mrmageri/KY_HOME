# ConfigToToml

Инструмент командной строки: преобразует текст на учебном конфигурационном
языке в TOML. Синтаксические и семантические ошибки выводятся в stderr с
указанием строки и столбца.

## Требования

- JDK 17+ (`javac`, `java` в `PATH`).

## Запуск
На Windows:

```bat
run.bat -i examples\web-server.cfg -o out\web-server.toml
```

## Синтаксис входного языка

| Конструкция | Пример |
|---|---|
| Комментарий | `\ до конца строки` |
| Число | `-?(\d+\|\d+\.\d*\|\.\d+)([eE][-+]?\d+)?` |
| Строка | `q(Это строка)` |
| Словарь | `$[ имя : значение, ... ]` |
| Имя | `[_a-zA-Z]+` |
| Константа | `var имя = значение` |
| Выражение | `{оп arg1 arg2 ...}` |

Операции и функции: `+`, `-`, `*`, `/`, `chr`, `pow`. Выражения
вычисляются на этапе трансляции; константы в TOML-документ не попадают —
в TOML уходят только поля верхнеуровневых словарей `$[ ... ]`.

### Пример

```
\ Конфигурация веб-сервера
var default_port = 8080
$[
  app : q(gateway),
  port : default_port,
  tls : $[
    enabled : 1,
    cert : q(/etc/ssl/server.crt)
  ],
  limits : $[
    max_conn : {* 2 5000}
  ]
]
```

Результат TOML:

```toml
app = "gateway"
port = 8080

[tls]
enabled = 1
cert = "/etc/ssl/server.crt"

[limits]
max_conn = 10000
```

Полные примеры из разных предметных областей:
`examples/web-server.cfg` (веб-сервер), `examples/game-level.cfg`
(игровой уровень), `examples/experiment.cfg` (численный эксперимент).

## Ошибки и коды возврата

| Код | Причина |
|---|---|
| 0 | успех |
| 1 | ошибка входного текста или ввода-вывода |
| 2 | некорректные аргументы командной строки |

Формат сообщения об ошибке входного текста:

```
Ошибка (строка 3, столбец 10): ожидалось ':' после имени поля, получено '1'
```
